# github-final-project

A hands-on project to practice Git and GitHub fundamentals including branching, merging, pull requests, and open-source contribution workflows as part of the IBM Developer Skills Network curriculum.

This project includes a simple interest calculator shell script that computes simple interest based on user-provided principal, rate of interest, and time period.

## Features

- Simple interest calculator (`simple-interest.sh`): computes Simple Interest = (P * R * T) / 100
- Demonstrates basic Git operations (commit, branch, merge, revert)
- Contains open-source community files (LICENSE, CODE_OF_CONDUCT, CONTRIBUTING)

## Getting Started

Clone this repository and follow along with the Git and GitHub excercises to learn version control.

```bash
git clone https://github.com/finishedsarevsh/github-final-project.git
```

## Usage

Run the simple interest calculator:

```bash
bash simple-interest.sh
```

You will be prompted to enter:
- Principal amount (P)
- Rate of interest per year (R)
- Time period in years (T)

The script will output: `Simple Interest = (P * R * T) / 100`
